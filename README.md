# PathSnap: Map-Matching & Route Reconstruction
UE24CS352A Machine Learning Hackathon, PES University (Team 3)

## Structure
- notebooks/ : EDA, feature engineering, model experiments
- src/ : data loading, features, HMM/Viterbi
- models/ : trained model and configuration
- results/ : experiment logs, metrics, plots
- maps/ : Folium maps
- api/ : FastAPI backend (Laptop 1)
- ui/ : evaluator UI (Laptop 2)

pip install -r requirements.txt
